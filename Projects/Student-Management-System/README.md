# Student Management System

A full-stack Student Management System built with HTML, CSS, JavaScript, Python Flask, and PostgreSQL.

## 📌 Project Overview

The Student Management System allows users to manage student records through a web-based interface.

The application provides functionality for:

- Adding students
- Viewing student records
- Searching for students
- Deleting students
- Storing student information permanently in PostgreSQL

## 🛠️ Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Python
- Flask
- Flask-CORS

### Database
- PostgreSQL
